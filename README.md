# GenAI: classic generative models

Notebooks implementing the generative models that came before diffusion and LLMs.

- **AutoEncoder:** compress images into a small latent vector and reconstruct them
- **Variational AutoEncoder:** a probabilistic latent space you can sample new images from
- **Generative Adversarial Network:** a generator and discriminator trained against each other

The VAE idea lives on in latent diffusion models like Stable Diffusion, which I'm exploring next.
